audio-latency-test

Measure speaker → microphone round-trip audio latency with a zero-dependency JavaScript module.

Turn the volume up, unplug headphones so the speakers play, keep the room quiet, then press Start. The page plays five short chirps per run and listens for them with the microphone (permission required). Nothing is recorded or uploaded.

What the number means

The result is output latency + input latency + the time the sound travels through the air (about 2.9 ms per metre). It is not the one-way delay you notice when watching a video. Echo cancellation, Bluetooth hands-free mode or a very quiet speaker can stop the chirps from being detected.

Use it in your own page

import { measureRoundTrip } from 'https://teasoup90.github.io/audio-latency-test/src/audio-latency-test.js';

const r = await measureRoundTrip({ runs: 5 });
console.log(r.medianMs, r.runsMs);
